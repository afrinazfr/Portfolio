# Afrina Zhafirah portfolio

A static site with no dependencies or build step.

- Preview: double-click `index.html`.
- Publish: upload this folder to any static host, such as Netlify Drop, GitHub Pages or Cloudflare Pages.

## Editing

- Portrait: save a 4:5 photo as `assets/portrait.jpg`
- Content: `index.html`
- Timeline dates: `ROWS` in `js/main.js`
- Colors and fonts: `:root` in `css/styles.css`
- Resume: `resume.html`, or replace `assets/Afrina-Zhafirah-Resume.pdf` with your own file under the same name
